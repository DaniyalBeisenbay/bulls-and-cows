## Текущий статус

Приватный учебный репозиторий создан: https://github.com/DaniyalBeisenbay/bulls-and-cows. Ветка `main` содержит только исходные README и .gitignore; реализация и полная история TDD находятся в `bulls-and-cows`.

GitHub Pages на текущем тарифе для этого приватного репозитория недоступен: Settings → Pages предлагает Upgrade или публичный доступ. Репозиторий сохранён приватным. Workflow Pages подготовлен с ручным запуском, чтобы обычный push не запускал заведомо недоступную публикацию. После решения вопроса хостинга можно включить автоматический запуск.
