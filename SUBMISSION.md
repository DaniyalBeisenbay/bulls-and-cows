Основной репозиторий сохранён приватным. Из-за ограничения тарифа Pages публикуется из отдельного публичного репозитория, содержащего только HTML, CSS и скомпилированный JavaScript. TypeScript, тесты и история TDD остаются в основном репозитории. Ветка main содержит только начальные README и .gitignore.

На публичном деплое проверены BIN-ограничения, блокировка параметров, фильтрация ввода, победа и время, сохранение рекорда после перезагрузки, верхний регистр HEX, отсутствие дубликатов и новая игра. Проверка: BIN 01 угадан с первой попытки, затем HEX ABCF принят; повтор abcf отклонён.

Отправку в RS App агент не выполнял. Для окончательной сдачи остаются скриншот, дедлайн курса и окончательная самооценка.
