# Bulls and Cows

[Play on GitHub Pages](https://daniyalbeisenbay.github.io/bulls-and-cows-play/)

Игра «Быки и коровы»: TypeScript, функциональное ядро, TDD, интерфейс на DOM API. Без бэкенда и без бандлера в production-сборке. Четыре системы счисления, длины 2–6, неограниченные попытки, личный топ-10 в localStorage.

## Запуск

Нужен Node.js 22.12+ (рекомендуется Node 24).

```sh
npm ci
npm run dev
```

Откройте адрес, выведенный Vite (обычно http://127.0.0.1:5173). Vite используется только как dev-сервер готовой папки dist. После изменений исходников повторите сборку.

```sh
npm test
npm run lint
npm run format
npm run build
```

`tsc` компилирует всю логику и UI в ES-модули `dist/js`. Скрипт сборки копирует HTML/CSS в `dist`. Эту папку можно разместить на любом статическом хостинге; относительные пути поддерживают GitHub Pages в подпапке репозитория. `body` исходного HTML содержит только script.

## Структура

- `src/core/` — пять обязательных функций и чистые переходы состояния.
- `src/main.ts` — DOM, события, время и хранилище.
- `tests/` — Vitest, 73 детерминированных проверки.
- [DESIGN.md](DESIGN.md) — алгоритмы, структуры, Big O и чистый код.
- [SUBMISSION.md](SUBMISSION.md) — состояние подготовки к сдаче и чек-лист.

## Git и сдача

Локальная ветка `main` содержит только README и .gitignore. Реализация находится в `bulls-and-cows`. Историю TDD смотрите через `git log --reverse --oneline main..bulls-and-cows`.

Для учебной сдачи нужен отдельный приватный GitHub-репозиторий. Не используйте squash, чтобы сохранить пары тестов и реализации. После подключения своего репозитория отправьте обе ветки, откройте PR из `bulls-and-cows` в `main`, не мержите. Публикация через Sites использует отдельное хранилище исходников и не заменяет учебный GitHub PR.

Результаты хранятся локально для каждого origin: рекорды localhost не переходят на другой домен. При повреждённых данных приложение восстанавливает пустую таблицу; при запрете localStorage сообщает, что результат доступен только до закрытия страницы.

## Публикация через GitHub

В `.github/workflows/pages.yml` настроены сборка, тесты и публикация `dist` из ветки `bulls-and-cows` через GitHub Actions. После создания приватного репозитория отправьте `main` и `bulls-and-cows`, выберите **Settings → Pages → Source → GitHub Actions** и разрешите ветку `bulls-and-cows` в правилах окружения `github-pages`, если включено ограничение веток. `main` по условиям задания остаётся без реализации.

GitHub Pages для приватного репозитория требует подходящего плана GitHub (Pro/Team/Enterprise). Если план не поддерживает Pages, оставьте учебный репозиторий приватным и используйте другой статический хостинг. См. [документацию GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages).

Редизайн: тёмная игровая комната, лаймовые акценты, отдельная панель настроек, игровое поле и история рядом; на мобильных — последовательная раскладка. Ядро и история TDD сохранены.

Учебный GitHub-репозиторий: [DaniyalBeisenbay/bulls-and-cows](https://github.com/DaniyalBeisenbay/bulls-and-cows). Репозиторий приватный. На текущем тарифе Pages для него недоступен, поэтому workflow публикации запускается вручную после решения вопроса хостинга. CI включён для push и PR.
